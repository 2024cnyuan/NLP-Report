# 报告素材（对应作业模板）

## 问题背景与选题

课程要求中阶建议至少三个模块，本组主动选择六个。纯 HTML/JS/CSS，浏览器直接打开，无后端。四项项目交互增强：计算显微镜、受控A/B、跨模块同权重解释、可复现笔记，不宣称学术首创。

## 研究方法

Codex 在 WSL 内完成仓库审查、数学参考、原生组件、离线 IIFE/Blob Worker、测试与截图迭代。保持既有 Vite/D3/Vitest/Playwright 依赖，没有引入后端、Python训练栈或其他图表库。只记录实际工具使用；其他平台对话、学生身份、老师评分待用户补充，不伪造对比。

## 实验设计

详见 architecture / algorithm-specs。训练集拟合词表；验证集仅用于可选 SVM 校准；测试集只评估，不选择轮数或预设深度模型领先。人工压力数据不报语义成绩。模型和数据快照按固定种子、类别顺序与版本保存。

教学情感集：AI辅助原创56句，32 train / 8 validation / 16 test，来源与许可明确。默认训练35轮，神经维度8，hidden8，batch4，lr0.04，seed42；SVM 为 hinge + L2。

## 实际结果

内置测试集的真实 Accuracy：NB 75.00%，SVM 81.25%，RNN 43.75%，Text-CNN 43.75%。Macro-F1：0.7333、0.8057、0.4353、0.4353。不能据此概括真实语料表现；训练数据小、OOV与否定转折导致明显错误。没有隐藏深度模型低分。

η=0.001 慢收敛、η=0.1 稳步下降、η=8持续震荡，由八个含冲突标签样本的真实 Logistic 更新重现，不使用预制曲线。算法验证含独立手算、逐权重有限差分、同步/分块一致与同模型解释一致。

## 测试与交互分析

数字结果与 screenshot 文件来自真正运行。数学单元报告、Playwright报告、Node与浏览器基准位于 evidence。使用 WSL Chromium；Windows验收未代替。图表点击能追到实际输入；CNN池化定位真实argmax；回退恢复既有状态；编辑参数标过期；模型修改生成新版本。

开发中发现并修复：IIFE top-level await；小数输入 stepMismatch；CBOW追踪中心而非被更新上下文；过长A/B权重文本；GloVe与负采样不同损失目标共轴；实验导入NB形状校验过严；导入数据不兼容时丢失训练控件；运行中编辑导致旧结果标新；诊断接口漏导入run。最新验证证据确认修复，不删除失败用例。
