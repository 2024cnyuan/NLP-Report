# 10分钟实际演示

1. 双击 release/index.html，说明无后端/无需网络。首页进入注意力。
2. 点击「理解→语言」权重，检查q、k、score和行概率和。锁定检查器再解除，展示数字来源。
3. 固定A→编辑掩码→屏蔽一格，观察行权重重新归一化与差值。保存命名「掩码对照」，导出JSON。
4. 打开损失，正常η0.1固定A，再点击η8；选择某个真实更新点，展示w、梯度、nextWeights，指出等高线只含两个自由参数。
5. 词向量用默认语料训练Skip-gram，定位「语言」，查看原空间邻居，再切CBOW/GloVe说明预测方向/目标差异。投影美观不等于语义质量。
6. 多模型工作台输入「虽然画面精美，但故事糟糕」，如实展示四预测和未校准说明。固定数据测试指标不一定深度模型好。
7. 表中筛选RNN错误，点击「解释」→同一权重与Token进入序列，单步/回退，查看真实最终CE梯度。CNN错误同理，点击pool定位argmax窗口。
8. 数据管理导入自己的二分类CSV，预览字段、划分和重复检查；不兼容时显式重新训练。说明短文本上限不会偷偷截断。
9. 笔记导入刚导出的JSON并重放，导出CSV与报告Markdown。最后展示test与bench证据，明确Windows验收与拓展档未测。
