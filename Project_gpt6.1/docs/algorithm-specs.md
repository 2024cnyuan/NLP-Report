# 数学定义与默认假设

双精度 CPU 参考；稳定 sigmoid、logsumexp、softmax、natural-log 交叉熵。种子42，固定 Mulberry32 随机数。独立有限差分 epsilon=1e-6、绝对梯度误差目标1e-5；远离 ReLU/max 不可导点。

注意力：q·k、q·k/√d 或 vᵀtanh(Wq q+Wk k+b)。默认 Wq/Wk 单位矩阵，b=0，v=1/√d。整行屏蔽拒绝；权重行和1。Token 哈希教学向量，不声称翻译对齐。

优化：两个自由参数的 Logistic：z=w₁x+w₂，固定八样本包含冲突标签，平均交叉熵梯度更新。曲线记录每次真实更新的固定全数据评估损失，训练批损失单列。等高线仅两自由参数，范围[-3,3]，超域轨迹不伪装在图内。

词向量：句界内窗口；Skip-gram 中心→每个上下文，CBOW 平均上下文→中心。负采样分布 freq^0.75，排除当前正样本、允许负样本重复；所有采样使用同一可保存随机状态。GloVe 使用有方向、按距离倒数计数的稀疏共现，f(X)=min(1,(X/100)^0.75)，训练输入/输出向量与两偏置，显示向量为两向量之和。NS 与 GloVe 损失不在同一纵轴比较。相似度遍历原空间全词表；PCA 基底只在维度与词表一致时复用。

序列：RNN h=tanh(Wx x+Wh h_prev+b)；LSTM 门顺序 i/f/o/g，默认忘记门偏置1；GRU 为 reset-before，候选 tanh(Wx x+Wh(r⊙h_prev)+b)，h=z⊙h_prev+(1−z)⊙candidate。状态梯度是真实 CE 反向传播结果，不是状态大小。log轴自适应正值下限，零值位于轴底并明确说明；范数用逐项 Math.hypot 避免小数平方下溢。训练使用完整 BPTT、批次平均梯度、真实全参数范数裁剪；最后批次裁剪前后值随模型保留。裁剪不消除梯度消失。

CNN：核宽覆盖整个 embedding 维度，沿时间维滑动；多宽多核→ReLU→每核 max-over-time→拼接→线性分类。短文本右补零到所需核宽，只产生一个含真实 Token 的有效窗口；没有纯 padding 窗口。max 并列取第一个，ReLU 零点导数0。不使用 dropout。训练全部 Embedding、卷积、偏置和分类参数。教学模型明确标识；实际模型保存真实权重版本。

分类：词表只从 train 拟合，未知词为模型定义的 OOV；NB 为多项式计数与 Laplace 平滑、log 空间；SVM 为真实 hinge+L2、稀疏计数特征与播种 SGD。SVM 默认 margin 而不是概率，Platt 校准只拟合 validation。RNN/CNN 复用上述定义。标签顺序保存在模型；无标签不生成 Accuracy/F1；零分母 Precision/Recall/F1 记0。解释 CE 的 target 与预测分离，标签不进入预测计算。

内置原创、AI辅助教学数据56条，32/8/16划分，训练种子42、神经维度8、隐藏8、35轮、lr0.04、batch4。预训练快照由 scripts/train.mjs 使用同源码生成，NB/SVM/RNN/CNN 测试 Accuracy 分别0.75/0.8125/0.4375/0.4375，不修饰深度模型较差的真实结果。自带数据相同 group 或精确重复 Token 不允许跨显式划分；基础中文切分是字符级，不冒充中文词级分词器。

单次训练仅保证相同版本/后端/输入顺序和配置的复现。实验重放从保存的初值配置重新训练，或使用保存的完整模型重新推理；暂停保持 Worker 内存状态，但不提供任意中途断电后继续训练。导入状态和声明成绩先视为未核验，重新计算后才能固定基线。
