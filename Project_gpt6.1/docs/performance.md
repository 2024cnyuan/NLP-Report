# 实测能力与预算

参考环境：Intel i9-14900HX，WSL2 Linux 6.18.33.2，WSL可见内存约15.4GiB，Node24.14，Chromium153.0.8010.12，离线IIFE+Blob Worker。确切环境与原始运行值在 evidence/bench.json、browser-bench.json。

| 目标档 | Node CPU 实测 | 浏览器 Worker 实测 | 解释 |
|---|---:|---:|---|
| 10,000条导入 | 中位数约27ms | 约113ms（含25行渲染与自动化往返） | 文件约0.27MiB，在10MiB预算内 |
| 注意力256×256,d32 | 中位数约15ms | 约90ms | 全65,536权重；16行计算切片 |
| Skip-gram100,000Token,V5000,d32,w2,k5,单轮 | 约4.93s | 约7.27s | 完整计算与PCA |
| CBOW相同档 | 约1.46s | 未单独浏览器测 | 负采样训练，真实方向区别 |
| GloVe100,000Token,V5000,d32 | 约0.41s | 未单独浏览器测此档 | 独立非零共现基准；不挪用Word2Vec成绩 |
| 5,000向量×20全词查询 | 中位数約44ms总计 | 图形另行检查 | 不是只搜显示标签 |
| 四模型10,000条×128Token,d8,h8 | 约11.8s | 约9.09s | 人工压力输入，无标签，未报准确率 |
| Logistic5,000次更新 | 中位数约238ms | 约832ms | 5,001原始评估记录 |
| RNN2,000条×64Token,d32,h32，单轮 | 约55.7s | 约60.1s | CPU完整BPTT，Embedding/循环/分类均训练 |
| CNN相同样本/长度/d32，单轮 | 约10.7s | 约9.9s | 宽2/3各3核，卷积/分类均训练，无隐藏循环层 |

重任务多为单次，不能把单次标成可靠p95。短基准3次报告中位数，不虚构稳定p95。耗时包括应用计算和任务通信（Node/浏览器记录范围分别解释），不是不同机器的承诺。

离线加载20次导航：中位数约43ms、p95约53ms，磁盘缓存未清除、不包含Chromium启动，不称完全冷启动。20轮控制确认：暂停p95约1ms、取消p95约31ms。20次页面内合成点击至下一帧p95约17ms；这不是操作系统真实输入延迟。重任务期间20ms心跳没有明显冻结，具体分位数可查原始记录。

未验收：Windows Chrome/Edge、后台页、真实硬件输入延迟、严格FPS测试、50,000条/50MiB导入、1,000,000Token/20,000词、注意力1024²等拓展压力档。堆的前后值不等于峰值；没有伪造精确峰值内存。低能力环境的CPU回退只验证小参考一致，性能可能明显降低。
