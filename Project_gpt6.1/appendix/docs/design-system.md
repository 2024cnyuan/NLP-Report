# 视觉与交互基线

科学出版物 + 实验工作台。浅灰绿底、白面板、深蓝灰正文、青绿操作、棕色对照。边框 #dfe7e9，强调 #087f8c。中文Noto Sans SC，英文/普通数字Inter，代码JetBrains Mono，数学公式KaTeX原配字体；全部本地内嵌，无网络字体。正文15px、参数13px，普通数字使用等宽数字特性。

桌面：230px 导航 + 主页面，250px 控制区 + 主图。窄屏控件先于图、局部矩阵滚动、导航抽屉。五尺寸以 Playwright 生成并实际查看截图。

顺序概率色带 [0,1]；正负数零中心发散色带；A/B 同域。数值点击/键盘可打开持久检查器，支持锁定。CSS尊重 reduced-motion。

单元图形最小高度40px，普通按钮40px。矩阵有单元精确值和行列名称，不仅悬浮提示。截图与对比度测试证据后续记录至 acceptance。

Attention/CNN/序列的计算链位于图形前，使用带序号的原生按钮，Tab/Enter可检查公式和完整代入值；桌面三列、中等宽度两列、手机一列。卡片注明实际选择的连接、窗口、时间步和维度，长向量仅预览，不伪造截断后的计算。分析指标与A/B表使用同一完成快照；小于1e-5的非零数使用科学计数法，避免将小梯度显示成0。
