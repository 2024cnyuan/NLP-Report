# 视觉与交互基线

科学出版物 + 实验工作台。浅灰绿底、白面板、深蓝灰正文、青绿操作、棕色对照。边框 #dfe7e9，强调 #087f8c。系统中文字体，无网络字体。正文15px、参数13px，数值等宽。

桌面：230px 导航 + 主页面，250px 控制区 + 主图。窄屏控件先于图、局部矩阵滚动、导航抽屉。五尺寸以 Playwright 生成并实际查看截图。
