# 算法定义

## M04（已实现）

空白分隔 Token。每个字符经 FNV-1a 变为一个维度的 ±1 计数，整向量 L2 归一；Q、K、V 均取这一确定性教学向量。映射未训练，不主张语义。维度 2–32，每侧最多 128 Token。原理模式限制每侧 12，实验模式仍计算全量。

- 点积：`Sij = Σt Qit Kjt`。
- 缩放点积：`Sij = (Σt Qit Kjt) / √d`。
- 加性：`Sij = Σt tanh(Qit + Kjt) / √d`，即 `Wq=Wk=I`、`b=0`、`va[t]=1/√d`。
- `Aij = exp(Sij − max(unmasked Si)) / Σk unmasked exp(Sik − max(unmasked Si))`；被屏蔽列严格为 0，整行全屏蔽时报错。
- `Oi,t = Σj Aij Vj,t`。

所有输入要求有限数且形状一致。`inspectCell` 返回输入向量、逐维项、分数、Softmax 分子分母、该列对输出的贡献。`tests/attention.test.js` 包括独立手算点积、缩放/加性、mask、形状、稳定 Softmax 与交叉熵。

## M06（初版已实现）

二元 Logistic，只有 `w=[w₁,w₂]` 两个自由参数，无偏置。`z=w·x`，`p=σ(z)`，每样本自然对数交叉熵用稳定形式 `softplus(z)−yz` 计算。全量平均损失 `L=Σ loss/N`，梯度 `∂L/∂w_j=Σ (p−y)x_j/N`，更新 `w←w−η∇L`。每个保存点都重新评估全体样本，曲线下采样只影响绘制。二维色图覆盖真实的两个自由参数，非任意深层模型投影。

默认数据由“好/差”两个计数构成，故意有同特征的冲突标签，使最优损失有下界。固定初值 `[1.2,−1]`；0.01、0.5、8 的预设分别产生慢、较快与震荡行为，`tests/optimization.test.js` 验证而非手绘曲线。测试还含独立有限差分梯度检查。迭代数 1–5000、样本数 2–2000。当前每次用全量梯度，无 mini-batch、暂停恢复或外部模型日志接入。
