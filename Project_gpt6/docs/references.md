# 参考与来源

- A1：仓库内 `原始题目/作业题目.docx`，课程原始范围与本地 HTML 要求。
- A2：仓库内 `原始题目/作业模板样例.docx`，报告章节与资源声明。
- P：仓库内 `prompt.md`，本组六模块、交互创新、性能档位与验收目标。
- 注意力公式：Vaswani 等，《Attention Is All You Need》，https://arxiv.org/abs/1706.03762 。本项目当前只有教学向量上的单头基础注意力，不是该论文模型复现。
- Vite 构建：https://vite.dev/guide/build 。Worker 与 `file://` 约束：https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Using_web_workers 。
- Vitest：https://vitest.dev/ 。D3：https://d3js.org/ 。已安装 D3，但当前样板图形由原生 HTML/CSS 绘制，尚未在运行代码导入 D3。

页面布局和代码为本项目编写。默认例 Token 为自编小样本，无外部语料或预训练模型。完整依赖清单见 `THIRD_PARTY_NOTICES.md`。
